# 机・椅子 移動計画ツール

[GitHub Pages](https://euphryuuu.github.io/desk-movement/) の「教室管理」で、旧教室・新教室の名前、校舎、階数、東からの順番を一覧で編集し、まとめて保存できます。「配置メモ」では階段の位置を設定できます。AI移動計画は登録済みの順番と階段の位置を参照します。

## 端末間での共有

アプリは学校の Firebase プロジェクト `desk-movement` を参照します。管理者が Firebase コンソールから次の初期設定を行います。

1. Authentication で「メール/パスワード」を有効にし、共有を許可する職員のアカウントを作成します。承認済みドメインに `euphryuuu.github.io` を登録します。
2. Realtime Database で既存のルールを確認し、`database.rules.json` の `plannerData` ルールを反映します。他のパスのルールがある場合は残し、上位パスに広いアクセス許可がないことを確認します。
3. Realtime Database で `plannerMembers/<職員のUID>` をブール値の `true` に設定します。職員は各端末で「共有ログイン」からサインインします。

未ログインでの設定はそのブラウザーに自動保存されます。「自動保存・同期中」と表示された状態での編集は共有データに自動保存されます。

「共有データのアクセス権がありません」が表示される場合は、Authentication の「ユーザー」でログインした職員の UID を確認してください。Realtime Database の「データ」タブで、ルート直下にある `plannerMembers` の子としてその UID を追加し、値を真偽値の `true` にします。「ルール」タブで `plannerData` の共有用ルールが公開済みであることを確認し、アプリで共有ログアウトしてからログインし直してください。
